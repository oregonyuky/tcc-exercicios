# 4. Resumo para sua Prova

| Operação | O que faz | Algoritmo |
| :--- | :--- | :--- |
| **Afinamento** | Reduz a espessura dos objetos | Zhang-Suen |
| **Extremidades** | Identifica as pontas | Contagem de vizinhos |
| **Rebarbas** | Remove ramificações curtas | Skeleton Pruning |
| **Pixels isolados** | Remove pontos sem vizinhos | Contagem de vizinhos |
| **Caroços/manchas** | Remove pequenos grupos | Componentes conectados |
| **Buracos internos** | Preenche regiões fechadas | Hole Filling / Flood Fill |
