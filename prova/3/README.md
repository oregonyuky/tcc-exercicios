# Contar células

Execute na pasta raiz do repositório:

```powershell
dotnet run --project prova/3/ContarCelulas.csproj
```

O programa usa `cells.png` por padrão. Para processar outra imagem, passe o
caminho como argumento:

```powershell
dotnet run --project prova/3/ContarCelulas.csproj -- caminho\da\imagem.png
```
