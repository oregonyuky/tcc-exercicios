# Filtro de mediana 5x5

Na raiz do repositório, execute:

```powershell
dotnet run --project .\3\4\filtroMediana5x5\FiltroMediana5x5.csproj -- .\3\4\filtroMediana5x5\imagem.jpg
```

O programa salva `imagem_mediana5x5.png` ao lado da imagem de entrada. Para
escolher outro caminho de saída, informe-o como segundo argumento.
