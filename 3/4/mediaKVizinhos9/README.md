# Média dos K vizinhos mais próximos

Na raiz do repositório, execute:

```powershell
dotnet run --project .\3\4\mediaKVizinhos9\MediaKVizinhos9.csproj -- .\3\4\mediaVizinhanca5x5\image.png
```

O programa salva `imagem_mediaK9.png` ao lado da imagem de entrada. Para
escolher outro caminho de saída, informe-o como segundo argumento:

```powershell
dotnet run --project .\3\4\mediaKVizinhos9\MediaKVizinhos9.csproj -- .\caminho\imagem.jpg .\caminho\resultado.png
```
